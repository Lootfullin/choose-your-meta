Российские фильмы


Для изображений требуется TMDB API key. Российский фильм определяется по стране производства RU; если страна не заполнена — по исходному языку ru. В каждой паре второй язык используется как резерв. Для каждого поля английское значение сохраняется, если русский вариант не найден. Локальные изображения имеют приоритет, фоны плагин не изменяет. Чтобы заменить уже сохранённые картинки, обновите фильм с включённой заменой изображений.
